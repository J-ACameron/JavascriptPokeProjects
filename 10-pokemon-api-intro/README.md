# Pokémon API Intro (First Fetch)

**Build:** Simple button that fetches a single Pokémon by ID from PokéAPI. Shows sprite, name, and types. Loading spinner while fetching. Error handling if the request fails.

**Concepts:** `fetch()`, `.then()` / `.catch()`, `response.json()`, loading states, error handling, basic Promise understanding.

**API:** `https://pokeapi.co/api/v2/pokemon/{id}`
